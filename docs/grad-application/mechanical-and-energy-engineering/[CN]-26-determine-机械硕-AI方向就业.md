# [CN]-26-交大机械硕士-AI方向就业

> 双非 AI 本科 → 交大机械硕士在读，方向为 Agent 开发 / AI Infra / 具身智能与机器人控制。
> 本文面向 2025 级及以后入学的交大研究生，分享研一阶段找实习、规划就业与升学的几点经验。
> 内容基于本人近六个月在实习僧等平台累计投递约两千份简历、经历三四轮集中面试的真实过程，部分细节可对照本人博客 [determine123.github.io/determine](https://determine123.github.io/determine/) 中的求职记录。

## 基本背景

- 本科：成都理工大学，人工智能专业（双非）
- 硕士：上海交通大学，机械与动力工程学院（ME），在读研一
- 目标岗位：Agent 开发、AI Infra、大模型应用 / 自动驾驶算法方向
- 主要投递渠道：实习僧、牛客、Boss 直聘、各大厂官网、学长学姐内推
- 主要面试对象：拼多多、腾讯、华为（OD）、清川院、吉翼智能、杉数科技、鹰瞰智翼、字节、科驾技术、滴滴、博格华纳、DENSO（电装）、PLUSCO 等

> 叠甲：以下结论来自"双非本 + 交大硕 + 该课题组"这一具体样本，不代表交大所有硕士的情况。不同课题组的氛围、导师风格、信息资源差异很大，建议优先咨询本课题组师兄师姐。

## 几点观察（就业）

### 1. "交大硕找实习"这件事，比想象中更早开始

研一开学前的暑假是第一个窗口。本人是从大三下联系完导师后开始投简历的，但真正进入集中面试是研一前的 3–4 月。时间线上：

- 3–4 月：第一轮海投（拼多多算法、腾讯官网、中小厂 PLC、华为 OD、清川院等）
- 6–7 月：第二轮，入职第一段实习后继续投下一段（吉翼、杉数、鹰瞰智翼等）
- 开学前一个月：第三轮，找学校附近的岗位（字节、科驾、滴滴、上海本地大/中厂等）

**"金九银十"这个说法，对找实习而言是反的——越早越好。** 研一上学期开始找，到研一下或研二上时手里已经有实习记录，后续投递的通过率高很多。

### 2. 学校背景是"入场券"，项目能力是"通行证"

近六个月下来的体感，企业排序大致是：**项目能力 > 专业基础 > 学校背景**。
交大硕士的背景在简历初筛阶段足够让你过 HR/机器筛选（大厂已开始用 LLM 初筛），但面试中真正决定去留的是你能不能把项目讲清楚、能不能回答追问。

这点对双非本科出身、靠交大硕士"洗学历"的同学尤其重要：**不要在简历上只写"上海交通大学硕士"就完了**，项目经历和量化指标才是面试的剧本。

### 3. 区域选择：江浙沪岗位密度远高于成都/重庆

本人在成都找过一段时间实习，后来发现上海、杭州、苏州的岗位数量和质量都明显高于成都。如果目标是互联网/智能制造/自动驾驶，**优先投江浙沪**；学校附近的岗位可以作为研一上学期的过渡。

### 4. 实习转正在 2025–2026 年仍然是最好的校招路径，但"提前批"更早

大厂提前批普遍在 7–8 月启动，实习会占用这段黄金时间。本人观察到的趋势：

- 提前批时间越来越早（7 月就开始）
- 实习表现好 + 导师同意 → 转正概率高
- 如果导师不放实习，建议入学前就提前确认，避免入职后出勤出问题

> 一个真实的教训：有面试官直接说"建议你等学校对接好导师再来"——这说明**导师态度**是实习岗面试中的隐性考核项。提前找学长学姐确认导师风格 + 学院实习政策，准备一段"出勤稳定性"的标准回答（含具体时间规划），不要被动暴露。

### 5. 简历：一页，STAR 结构，量化指标

详细写法见本人博客《找实习-简历编写指北》，核心要点：

- **一页为佳**，教育背景放最前，实习/项目经历按含金量排
- **STAR 结构**：背景 → 你做了什么 → 量化结果
- **量化指标**是命门：没有指标的简历等于没做过
  - ❌ "开发了 XX 系统的登录注册功能"
  - ✅ "增加索引并引入 Redis 缓存后，接口 QPS 从 100 提升至 800，响应时间降低 60%"
- **Hook 技巧**：把具体技术提升到范式层面，引诱面试官追问（例："熟悉数据库技术，了解 NoSQL & SQL 范式，例如 MongoDB, MySQL"）
- **垃圾模块勿写**：学生会、个人自述、兴趣爱好，对技术岗全是扣分项
- **诚信底线**：写了但讲不出来的，默认你是抄的/假的

### 6. 面试准备：围绕 JD 准备，而不是"背八股"

- 投递前必须解读 JD，把简历往 JD 的方向倾斜
- 准备"3–5 分钟能讲清楚"的项目介绍，覆盖：做了什么、难点在哪、怎么解决、量化结果
- 对 AI 方向岗位，RAG 全链路、Agent 工作流、模型评测是高频考点
- 不要混淆概念（例：PPO 是 on-policy + clipped objective，SAC 是 off-policy + 最大熵 + replay buffer，区别不是"短期/长期奖励"）
- 不确定的技术，诚实说"了解原理但没独立做过"，比夸大后被追问到说不出强

## 几点观察（升学）

### 1. 交大硕士 → 读博/出国，时间线比本科申请更紧凑

本人本科是双非，硕士在交大，如果要继续读博或出国，建议**研一上学期就确定方向**：

- 直博/出国：研一上确定导师 + 研究方向，研一下开始套磁/准备文书
- 保研（针对本科）：交大保研比例近年有提升，但双非本科进交大读研后想"保研出国"基本不成立，主要路径是考研直博或申请制 PhD
- 考研：交大考研竞争烈，除非有明确目标导师，否则不推荐"为读而读"

### 2. 是否读博，想清楚再决定

读博的 ROI 因人而异。如果目标是学术界或特定高端研发岗，读博是必须的；如果目标是工业界，**硕士 + 实习 + 项目**的组合在大多数情况下比"硕士 + 博士"更有性价比（除非是顶会论文密集的方向）。

### 3. 信息差是最大的坑

交大各院系、各课题组的资源、氛围、信息渠道差异很大。建议：

- 入学前：通过学长学姐、QQ 群、知乎、小红书了解目标课题组的就业/升学情况
- 入学后：主动和课题组师兄师姐交流，不要只靠导师
- 关注学院官网的就业去向统计、校友内推渠道

## 给新入学同学的几点具体建议

1. **研一暑假前就开始准备简历**，哪怕没有实习，课程项目 + 自学项目也能撑起第一版
2. **LeetCode 保持手感**，AI 方向岗也常考算法题
3. **找一段实习**，哪怕是短平快的，有实习记录后续投递通过率高很多
4. **确定方向**：Agent / AI Infra / 自动驾驶 / 具身智能 / 传统 ME 数字化，不同方向的知识栈差异大，不要"什么都学一点"
5. **利用交大校友网络**：上海本地的很多公司都有交大校友，内推比海投效率高
6. **不要只盯上海**：杭州（阿里）、深圳（腾讯）、北京（字节）的岗位质量和数量都不输上海
7. **关注"提前批"时间线**：7–8 月是黄金窗口，实习如果冲突要提前和导师沟通
